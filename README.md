# Final Project – MEC_51057  
## Wind Energy Power Prediction (VRE)

This repository contains the final project for the course MEC_51057, focused on the prediction of Variable Renewable Energy (VRE) power in a wind energy context. The project explores data-driven methods to model and forecast wind power generation, supporting improved planning and integration of renewable energy into the power grid.
